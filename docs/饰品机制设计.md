# 饰品机制设计

> 目标：把"每件饰品 = 一条固定属性"的单调设计，改造成**看局势、要取舍、能组合**的玩法系统。

## 一、设计原则

1. **每件饰品都要有"使用场景"**，而不是无脑数值。玩家换装应该是在回答"我现在要干什么"。
2. **有代价才有选择**。高阶饰品带明确负面，而不是纯上位替代。
3. **组合 > 单件**。派系共鸣让"低阶但同派系"成为一种可行构筑。
4. **接入本模组已有的系统**（生命数、边界缩圈、队伍、升华、感染对抗），让饰品是这个玩法的一部分，而不是外挂的数值表。

---

## 二、六大机制

### 机制 1 · 情境效果（Conditional Effects）

每条效果都可以带一个 `when` 条件，只有条件成立时才生效。

| 条件 id | 含义 |
| :--- | :--- |
| `always` | 无条件（默认） |
| `low_health` | 生命 ≤ 35% |
| `mid_health` | 生命 ≤ 60% |
| `full_health` | 满血 |
| `hurt` | 生命 ≤ 70% |
| `night` | 主世界夜晚 |
| `day` | 主世界白天 |
| `underground` | y < 55 |
| `high_altitude` | y > 120 |
| `low_light` | 光照 ≤ 7 |
| `in_water` | 处于水中 |
| `in_rain` | 露天且在下雨/雷暴 |
| `burning` | 正在着火 |
| `sneaking` | 潜行中 |
| `sprinting` | 疾跑中 |
| `hungry` | 饥饿值 ≤ 6 |
| `recent_kill` | 10 秒内击杀过生物 |
| `low_lives` | 本队剩余生命数 ≤ 2 |
| `last_stand` | 本队只剩自己一个存活玩家 |
| `outnumbered` | 12 格内敌人（敌对生物 + 敌对玩家）数量 > 队友数量 |
| `near_border` | 距离世界边界 ≤ 64 格 |
| `in_nether` | 在下界 |
| `in_end` | 在末地 |

### 机制 2 · 派系共鸣（Faction Resonance）

每件佩戴类饰品属于一个**派系**（取自图标配色主题）：

| 派系 | id | 主题 |
| :--- | :--- | :--- |
| 绯红 | `crimson` | 红宝石 / 血晶 / 赤瞳 |
| 蔚蓝 | `azure` | 蓝晶 / 碧蓝 / 寒冰 |
| 紫晶 | `amethyst` | 紫水晶 / 紫罗兰 / 奥秘 |
| 黑曜 | `obsidian` | 黑曜石 / 暗影 / 黑铁 |
| 苍翠 | `verdant` | 绿宝石 / 白骨 / 草药 |
| 鎏金 | `gilded` | 黄金 / 白银 / 珍珠 |

**生效的佩戴类饰品（同类只取品阶最高的一件）中，同派系数量达到 2 件 → 共鸣 I；达到 3 件 → 共鸣 II。**

- 共鸣效果由 `data/life_contract/accessory_resonance.json` 定义，与单件效果独立叠加；
  触发 / 断开时会在 action bar 提示玩家。
- 这直接对抗"只看品阶"的最优解：想要共鸣 II，就得放弃某些类别的最高阶饰品。

### 机制 3 · 击杀充能（Kill Charge）

部分饰品带 `charge` 字段：

```jsonc
"charge": {
  "max": 8,                                  // 层数上限
  "per_stack": [ { "type": "ATTACK_DAMAGE", "value": 0.4 } ],  // 每层加成
  "decay_ticks": 1200,                       // 每 1200 tick 掉 1 层（0 = 不衰减）
  "lose_on_hurt": 2                          // 每次受伤掉几层
}
```

- 击杀生物 +1 层（需玩家造成击杀）。
- 受伤掉 `lose_on_hurt` 层；死亡清零。
- 形成"滚雪球 vs 及时止损"的博弈：充能满的玩家会被优先集火。

### 机制 4 · 主动技（Active Skill）

部分饰品带 `active` 字段，按 **G 键**释放。

```jsonc
"active": { "kind": "WARD", "value": 8, "duration": 200, "cooldown": 1800 }
```

| kind | 效果 |
| :--- | :--- |
| `BURST` | 爆发：力量 + 迅捷（value 决定等级，duration 决定时长） |
| `WARD` | 护盾：抗性提升 + 伤害吸收（value = 吸收点数） |
| `MEND` | 治疗：立即回复 value 点生命 + 再生 |
| `DASH` | 冲刺：沿视线弹射 + 短暂迅捷 |
| `PHASE` | 潜行：隐身 + 迅捷 |
| `PURGE` | 净化：清除全部负面效果 + 短暂再生 |
| `MARK` | 标记：给 16 格内敌人发光 + 虚弱 |
| `RALLY` | 集结：给 16 格内队友力量 + 抗性 |

**释放规则**：一次只触发一件。在所有已佩戴饰品中，取**品阶最高、且冷却已结束**的那一件；同阶按 id 字典序。冷却按饰品 id 独立记录，换装不会清冷却。

### 机制 5 · 代价（Drawback）

高阶饰品的强力效果配明确负面，直接在 `effects` 里写负值，例如：

```jsonc
{ "type": "MAX_HEALTH", "value": -6 }
```

Tooltip 里负值用红色显示，让玩家一眼看到代价。

### 机制 6 · 消耗品多效果

`consume` 从单条改为数组，药水可以同时给"即时效果 + 短时增益"。

## 三、JSON Schema（`data/life_contract/accessory_catalog.json`）

根节点是数组，每个元素：

```jsonc
{
  "id": "ruby_pendant",              // 必填，物品 id
  "texture": "ruby_pendant",         // 贴图名，默认 = id
  "category": "pendant",             // pendant|ring|charm|crown|amulet|consumable|material
  "faction": "crimson",              // crimson|azure|amethyst|obsidian|verdant|gilded|none
  "tier": 2,                         // 1..5
  "name_zh": "红宝石坠",
  "name_en": "Ruby Pendant",
  "effect_zh": "最大生命 +4；生命 ≤35% 时护甲 +4",   // 展示用文案，需与 effects 一致
  "effect_en": "...",
  "effects": [
    { "type": "MAX_HEALTH", "value": 4 },
    { "type": "ARMOR", "value": 4, "when": "low_health" }
  ],
  "charge":  { ... },                // 可选
  "active":  { ... },                // 可选
  "consume": [ { "type": "HEAL", "value": 14 } ],   // 仅 consumable
  "price": 120,                      // 商店价格（升华）
  "recipe": { "ingredients": ["..."], "sublimation": 0 }
}
```

`AccessoryEffectType` 可选值：
`MAX_HEALTH` `ARMOR` `ARMOR_TOUGHNESS` `ATTACK_DAMAGE` `ATTACK_SPEED`
`MOVEMENT_SPEED_PERCENT` `KNOCKBACK_RESISTANCE` `LUCK`
`SUBLIMATION_PERCENT` `LIFESTEAL_PERCENT` `DAMAGE_REDUCTION_PERCENT`
`NIGHT_VISION` `FIRE_RESISTANCE` `WATER_BREATHING` `REGENERATION` `SATURATION`
`JUMP_BOOST` `HASTE` `RESISTANCE`
`HEAL` `FEED` `XP`（仅消耗品）

## 四、共鸣表（`data/life_contract/accessory_resonance.json`）

```jsonc
[
  {
    "faction": "crimson",
    "name_zh": "绯红共鸣",
    "name_en": "Crimson Resonance",
    "desc2_zh": "...", "desc2_en": "...",
    "effects2": [ { "type": "LIFESTEAL_PERCENT", "value": 4 } ],
    "desc3_zh": "...", "desc3_en": "...",
    "effects3": [ { "type": "LIFESTEAL_PERCENT", "value": 8 }, { "type": "ATTACK_DAMAGE", "value": 2 } ]
  }
]
```

## 五、数值基调

| 品阶 | 定位 | 大致强度 |
| :--- | :--- | :--- |
| T1 | 过渡，可无条件常驻 | 1 条小效果 |
| T2 | 单点专精 | 1~2 条，合计约 T1 的 2 倍 |
| T3 | 情境专精 | 常驻小幅 + 条件大幅 |
| T4 | 双机制 | 常驻 + 条件，或 常驻 + 充能/主动 |
| T5 | 构筑核心 | 强力机制 + **明确代价** |

共鸣 I 约等于一件 T3 的强度；共鸣 II 约等于一件 T5 的强度。
